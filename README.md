# Учебный интернет-магазин — контрольная работа №1

## Тема и описание

Тема контрольной работы №1: «HTML и CSS: разработка многостраничного сайта».

Проект выполняется в рамках дисциплины «Фронтенд и бэкенд разработка». Это учебный интернет-магазин товаров для учёбы и рабочего места. На сайте можно перейти от каталога к описанию товара, сравнить товары и открыть форму заявки.

## Страницы проекта

- `index.html` — главная страница: первый экран, преимущества, популярные товары и модальное окно с заявкой;
- `catalog.html` — каталог с категориями, карточками товаров и статическим блоком фильтров;
- `product.html` — изображения, описания, цены товаров и таблица сравнения;
- `order.html` — страница оформления заявки;
- `contacts.html` — контактная информация и ссылка на форму заявки.
- `student.html` — информация о студенте, выполнившем проект.

## Структура проекта

- `index.html` — главная страница;
- `catalog.html` — каталог товаров;
- `product.html` — описание и сравнение товаров;
- `order.html` — оформление заявки;
- `contacts.html` — контактная информация;
- `student.html` — информация о студенте;
- `css/style.css` — общий файл стилей;
- `js/main.js` — открытие модального окна и базовая проверка формы;
- `images/` — локальные SVG-изображения товаров;
- `README.md` — описание проекта;
- `.gitignore` — список файлов, исключённых из Git.

## Используемые технологии

- HTML и семантическая разметка;
- CSS, переменные, Flexbox, Grid и БЭМ-классы;
- JavaScript для модального окна и проверки формы;
- Git, GitHub и GitHub Pages.

## Как посмотреть проект

Откройте [опубликованный сайт](https://nikak14.github.io/kr1-html-css-shop/) или файл `index.html` в браузере. Меню ведёт на все пять страниц, ссылки «Подробнее» — к описаниям товаров, а «Заказать» — к форме. Данные формы проверяются в браузере и не отправляются на сервер.

## Постановка контрольной работы №1

Тема контрольной работы №1: «HTML и CSS: разработка многостраничного сайта».

В рамках контрольной работы необходимо разработать многостраничный HTML/CSS-сайт интернет-магазина или каталога услуг.

Проект должен включать главную страницу, каталог, страницу товара, страницу заявки, контакты, семантическую HTML-разметку, внешний CSS-файл и общую навигацию.

## Самостоятельные доработки

- Созданы локальные иллюстрации трёх товаров и каталог с категориями.
- Добавлены бейджи карточек, таблица сравнения и ссылки к описанию каждого товара.
- Каталог разделён на сетку карточек и боковую форму фильтров; фильтры показаны как учебный макет.
- Добавлены видимый фокус, подсветка ошибок формы, хлебные крошки и фиксированная ссылка «Наверх».
- Для карточек, меню и формы применены БЭМ-классы.

## История выполнения

- Практическая работа 1: создан Git-репозиторий, опубликован проект на GitHub Pages.
- Практическая работа 2: создан HTML-каркас стартовой страницы и выполнено базовое CSS-оформление.
- Практическая работа 3: добавлена форма заявки, модальное окно и базовая валидация.
- Практическая работа 4: добавлены CSS-переменные, состояния интерфейса и упорядочена структура стилей.
- Практическая работа 5: создана многостраничная структура сайта, добавлены единая навигация и якорные ссылки.
- Практическая работа 6: добавлены Flexbox-навигация и Grid-раскладка карточек и каталога.
- Контрольная работа №1: добавлены страницы товара и заявки, таблица, Flexbox/Grid, БЭМ и позиционирование.

## Использование Flexbox и Grid

- Flexbox используется для основного меню и внутренней структуры карточек товаров.
- CSS Grid используется для сетки карточек и страницы каталога с фильтрами и списком товаров.
